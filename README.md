
# Pro Jersey 🏆

Site moderno de vendas de camisetas de times feito com React + Vite + Tailwind CSS.

## 📁 Estrutura

- React com Tailwind
- Layout responsivo e otimizado para conversão
- Páginas: Home, Coleções, Sobre, Contato, Carrinho
- Logotipo incluso em SVG
- Imagens de camisetas (simuladas)

---

## 🚀 Como publicar na Vercel

1. Faça upload do projeto no GitHub:
    ```bash
    git init
    git add .
    git commit -m "commit inicial"
    git remote add origin https://github.com/seu-usuario/pro-jersey.git
    git push -u origin main
    ```

2. Acesse [https://vercel.com/import/git](https://vercel.com/import/git)

3. Escolha o repositório `pro-jersey`

4. Vercel detectará automaticamente Vite. Clique em **Deploy**

5. O site ficará disponível em `https://pro-jersey.vercel.app`

---

## 🌐 Como publicar no Netlify

1. Acesse [https://netlify.com](https://netlify.com) e crie uma conta
2. Faça upload manual da pasta do projeto ou conecte o GitHub
3. Configure:
    - Build command: `npm run build`
    - Publish directory: `dist`
4. Clique em Deploy
